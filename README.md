## Tujuan Praktikum
1. Memahami dasar penggunaan JavaScript pada website
2. Menerapkan logika percabangan (if/else, switch)
3. Membuat interaktivitas pada HTML (event, DOM)

## Daftar File
- `index.html` : File utama berisi struktur HTML dan tampilan program
- `script.js` : File berisi logika JavaScript (cek genap/ganjil, daftar menu, kalkulator nilai)

## Fitur Program
1.  **Cek Ganjil Genap** - Input angka, tampilkan hasil genap/ganjil di Console & Alert
2.  **Ubah Warna Background** - Mengubah warna dengan JavaScript
3.  **Daftar Menu Makanan** - Memilih menu dan menampilkan total harga (menggunakan switch case)
4.  **Kalkulator Nilai Akhir** - Input Tugas, UTS, UAS untuk menghitung nilai akhir dan grade (A,B,C,D,E) + memperbaiki bug di `document.writeln`

## Cara Menjalankan
1. Download atau clone repository ini
2. Buka `index.html` di browser (Chrome)
3. Tekan `F12` -> buka tab `Console` untuk melihat output
4. Coba interaksi pada setiap fitur
